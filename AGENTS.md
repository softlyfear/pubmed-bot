# Правила проекта

## Git: коммит и пуш без отдельного подтверждения

- Пользователь заранее разрешил `git commit` и обычный `git push` для завершённых
  изменений в рамках поставленной задачи. Их можно выполнять автоматически, без
  отдельной просьбы или подтверждения, после успешных проверок проекта.
- Перед коммитом проверить рабочее дерево и staged diff; добавлять только изменения
  по задаче. Сохранять посторонние правки пользователя и не коммитить секреты.
- Пушить в настроенную удалённую ветку текущей рабочей ветки. Это разрешение не
  распространяется на force push, переписывание опубликованной истории и удаление
  удалённых веток: для них нужно явное согласие пользователя. Проверки и хуки не обходить.
- Автор и коммиттер — пользователь из `git config user.name` / `user.email`.
  Атрибуция ИИ — `Co-Authored-By: Codex <фактическая модель и версия>` без почты;
  модель и адреса ИИ-сервисов не выдумывать.
